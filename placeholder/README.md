# Portfolio placeholder page

View-only landing page from Figma [`148:765`](https://www.figma.com/design/AzsPDKM5dJw3QhVHMA8Qod/P?node-id=148-765&m=dev). Nothing is clickable.

This folder lives inside the main **portfolio** repo. Edit files here and push to `main` on `ShivanshRana13/portfolio`.

## Local preview

```bash
cd placeholder
python3 -m http.server 8080
# open http://localhost:8080
```

## Deploying to your domain (optional, later)

When you want this page on a custom domain while the full site is still in progress, you can either:

- Point your domain at a **GitHub Pages** deploy of just these files, or
- Swap the main portfolio deploy to serve this folder temporarily

Ask in Cursor when you’re ready — we’ll wire it up from this single repo.
